⚽ International Football Analysis

A Data-Driven Exploration of 150 Years of Global Football

This project visualizes over 48,000 international football matches (1872–2023) to uncover long-term trends in goal scoring, competitiveness, and tournament evolution.

It combines clear Python analytics with a modern dark-themed visualization style to tell the story of football’s global growth and tactical transformation.

---

📊 Key Insights

•	Home teams win nearly half of all international matches — confirming a lasting home advantage.

•	Average goals per match have steadily declined, reflecting the rise of tactical discipline and defensive balance.

•	Friendly matches account for almost half of all games, illustrating football’s deep cultural and informal roots.

•	Europe dominates in total matches played, while other continents show rapid expansion in recent decades.

•	Goal margins have narrowed significantly — international football is now more balanced and competitive than ever.

---

🧠 Technologies Used

•	Python — core programming and analysis

•	NumPy — numerical operations

•	Pandas — data cleaning and manipulation

•	Matplotlib — custom dark-themed plots

•	Seaborn — complementary data visualization styling
